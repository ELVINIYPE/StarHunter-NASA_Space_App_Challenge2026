# StarHunter-NASA_Space_App_Challenge2026
Project StarHunter Game: NASA Space App Challenge 2026 entry by team StarHunter. An interactive 2.5D  1-4player space mission game teaching 26 complex aerospace concepts featuring an Arduino powered lunar rover that checks for water on lunar surface. We demonstrate Apollo , Artemis missions. ‹At the last level we build moon colony and go to Mars
